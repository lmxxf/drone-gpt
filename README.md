## 一、 核心方法论：[`AGENTS.md`](./AGENTS.md) 科研工程协议架构

针对长程科学计算与多物理场约束优化中大模型易陷入“统计惯性续写”或“单一超参数盲目微调死循环”的症结，[`AGENTS.md`](./AGENTS.md) 确立了三层认知与工程闭环架构：

1. **认知几何校准（从“梦游续写”切换到“在场审视”）**：发出首个工具调用前先在全局注意力场还原自由度维数、硬约束死线、目标曲率与验证代价；严格区分**实测/推导事实**与**先验猜测**；沿同一方向连续两次修改未改善指标时强制触发**二阶递归制动**（排查积分网格混叠或切换显式守恒流形投影）。
2. **第一性原理降维与验证器驱动闭环**：动手前先核算内存/显存、求积复杂度、采样方差与 `float64` 精度；最短路径跑通官方基线（Zero-to-One Baseline）；以 JAX/SIMSOPT 伴随梯度（VJP）或物理守恒流形投影开展多阶段寻优，最终候选解 **100% 由未修改的官方 `eval.py` 全量协议**独立裁决，严禁任何静默降级（silent fallback）或硬编码凑数。
