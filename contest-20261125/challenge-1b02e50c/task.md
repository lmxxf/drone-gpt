# 留住聚变热量，用三维磁场抑制湍流热损失

把带电粒子留在磁场中，热量就一定留得住吗？在仿星器里，外部线圈形成三维磁场，精心设计的磁几何可以减小粒子的径向漂移。但大量粒子组成的等离子体还会产生集体波动，把热量从高温核心输送到外侧。

这意味着，一个擅长约束单个粒子的磁场，仍然可能有较强的湍流热输运。磁场设计需要同时面对这两件事：留住高能粒子，也抑制集体波动造成的热量流失。

**你的任务是改变等离子体边界的三维形状，在保持设备尺度、场强和基本磁约束性能的同时，降低十二个规定工况中最大的非线性湍流热流。**

## 1. 科学目标（Goal）：让三维形状成为控制热输运的变量

### 1.1 温度梯度为何会驱动热量流失？

聚变需要高温核心，而温度通常向外降低。这个梯度为一类称为离子温度梯度模（ITG）的波动提供能量。伴随波动的电场扰动可以驱动横跨磁力线的运动，把不同温度的等离子体交换位置，形成向外的热输运。

磁场的曲率、强弱变化和沿场结构会影响这些波动。不过，波动最初增长得多快，与它们相互作用、进入非线性状态后持续带走多少热，是两个不同的问题。本题使用非线性演化得到的热流作为主要评价量。

### 1.2 在相同设备尺度下减少热量流失

你从公开的准轴对称磁构型出发，修改外边界的 Fourier 系数。评估器在固定小半径、体积范围和场强下重新求解内部磁场。α 粒子约束、有效波纹度、旋转变换和其他磁几何条件也必须保留。

同一个形状还要接受十二个测试点的检验：四个沿磁力线延伸的局域计算区域，各配三个温度梯度。将各点热流换算到统一单位，取其中最大值作为优化目标。这样，优化始终针对当前热损失最大的工况；最大值降低，不要求每点都低于公开起点。

### 1.3 如何判断一次形状改动是否真的有用？

GX 回旋动理学程序对快速回旋运动作平均，保留影响输运的较慢动力学，计算波动的非线性演化。热流会随时间起伏，因此评估还要比较独立随机初态、统计窗口和数值分辨率。优化既需要理解几何与湍流的关系，也需要分辨有限计算中的真实改善和统计波动。[非线性湍流优化研究](https://arxiv.org/abs/2310.18842)

最终提交 `boundary.json`。改进后的磁边界在保留磁约束的同时降低规定工况的热流，可作为后续温度剖面和线圈研究的候选。

## 2. 固定设备尺度，保住磁约束（Input and constraints）

设计对象是等离子体最外层磁面的形状。统一条件如下：

| 条件 | 本题取值与含义 |
|---|---|
| 平衡 | 固定边界、仿星器对称、真空；p=0，各磁面包围的净环向电流 I_t=0 |
| 场周期 | N_FP=2，所有候选与参考相同 |
| 尺度 | 有效小半径 a=1.70 m；缩放后体积与参考相差不超过 0.1% |
| 参考体积 | V_ref=581.8735601800271 m³，由提供的 QA+well 边界按本题几何定义计算 |
| 场强 | 轴上 Boozer 零模 B₀₀(0)=5.70 T |
| 高能粒子 | 3.5 MeV α 粒子、无碰撞导心、E_r=0；从 s=0.25 发射，追踪 0.2 s |
| 湍流 | 静电、一个动力学离子物种、绝热电子；T_i/T_e=1；固定原生碰撞模型 |
| 可修改量 | 边界 Fourier 系数；0≤m≤5、abs(n)≤5 |

s 是归一化环向磁通，磁轴为 0、边界为 1，ρ=√s。本题采用低 β 模型，在真空磁几何上计算固定背景剖面下的局域湍流。

边界先缩放到规定小半径，再独立检查体积。固定 a 和 V，也固定了有效纵横比的范围。

| 要求 | 达标条件 | 希望保住的性能 |
|---|---|---|
| 不扩大燃料区域 | abs(V/V_ref−1)≤0.001 | 在共同设备尺度上比较热流 |
| 留住高能粒子 | α 损失比例的 Wilson 95% 上界≤0.05 | 保留聚变 α 加热和减少逃逸粒子的条件 |
| 限制新经典输运 | 五个指定磁面 max(ε_eff)≤0.01 | 改善湍流时仍保留低有效波纹度 |
| 保持磁力线扭转 | s∈[0.05,0.95] 上 min(abs(ι))≥0.30 | 外部磁场提供足够的旋转变换 |
| 保持真空磁阱 | 同一区间逐面 W≥0 | 为后续加压和稳定性研究保留有利起点 |
| 避免过度拉长 | κ_max≤8 | 限制极端截面形状 |
| 保留线圈空间的可能性 | 边界 min(L_∇B)≥2.4 m | 使用已有经验标定的线圈空间代理量 |

上述门槛结合公开参考构型在同一设备尺度下的磁约束计算设定，并对 α 损失使用统计上界。L_∇B 采用线圈空间的经验代理量。[磁场梯度尺度研究](https://arxiv.org/abs/2309.11342)

### 2.1 十二个固定湍流测试点

全部测试在 s=0.5 上进行。取四根通量管，每根覆盖约 75a 的物理沿场长度；中心使用 PEST 直场线极向角和柱坐标环向角：

| 通量管 | θ_PEST 中心 | φ 中心 |
|---|---:|---:|
| T00 | 0 | 0 |
| T10 | π | 0 |
| T01 | 0 | π/N_FP |
| T11 | π | π/N_FP |

每根管分别计算 a/L_Ti=3、4、5，密度梯度固定 a/L_n=0.9。这里的梯度相对于 x=a√s 定义；离子参考密度、温度、质量和电荷在 GX 中均归一为 1，T_i/T_e=1，碰撞参数 νa/v_ti=0.01。温度、密度与物种的公共归一不由参赛者修改。

3 和 0.9 参考了文献基于 W7-X 典型测量采用的工况；4、5 是本题选择的邻近梯度测试。四个通量管中心也采用该研究覆盖不同场线位置的办法。[参数依据](https://arxiv.org/html/2502.11657v2)

## 3. 从一个公开边界出发

起点为 `/app/reference_configurations/landreman_paul_2022_QA_well.json`，来自 Landreman–Paul 的公开构型。文件名中的 QA 指“准轴对称”：磁面本身可以是三维的，但在适合描述粒子运动的磁坐标中，磁场强度近似具有轴对称性，有利于抵消粒子的径向漂移；well 表示设计同时考虑了真空磁阱。

这个起点提供了一种把单粒子约束做好的形状。你要进一步探索：改变它的哪些形状分量，能在保住第 2 节要求的同时，让非线性波动少带走热量？可以从它逐步调整，也可以生成新的边界；最终都在同一设备尺度和十二点条件下比较。

这份边界是可直接提交的搜索起点，已有记录显示它通过七项磁与几何约束。它的热流成绩不进入任何候选的评分公式；每份提交都按相同规则独立计算。

## 4. 用 JSON 提交新的磁边界

输入包括第 2 节的固定设备与湍流条件、第 3 节的公开参考边界，以及 `resources.yaml` 列出的原生代码、物理配置和复算资料。设计变量为边界系数。

最终提交工作目录中的 **`boundary.json`，即 `/app/boundary.json`**。文件只有几何参数：

```json
{
  "nfp": 2,
  "modes": [
    {"m": 0, "n": 0, "rbc": 1.0, "zbs": 0.0},
    {"m": 1, "n": 0, "rbc": 0.17, "zbs": 0.17}
  ]
}
```

这个圆环只演示格式，缺少仿星器所需的三维扭转，不是达标构型。展开约定为：

```text
R(θ,φ) = Σ rbc(m,n) cos(mθ − n N_FP φ)
Z(θ,φ) = Σ zbs(m,n) sin(mθ − n N_FP φ)
(x,y,z) = (R cosφ, R sinφ, Z)
```

θ 是边界参数角，φ 是柱坐标环向角，均用弧度。边界参数角与通量管使用的 PEST 角不是同一个角。JSON 中 n 不含 N_FP；VMEC 的 RBC(n,m)、ZBS(n,m) 下标先 n 后 m。

- 顶层恰有 `nfp`、`modes`；nfp 必须是整数 2，modes 是非空数组。
- 每个模恰有 m、n、rbc、zbs；m、n 为整数，系数为有限数，不接受布尔值、NaN 或 Infinity。
- 0≤m≤5，abs(n)≤5；m=0 时 n≥0；同一 (m,n) 不得重复。未列出的模为零。
- 必须有 rbc(0,0)>0、zbs(0,0)=0；边界闭合、无自交、处处 R>0。
- 系数用任意一致的长度单位，评估器统一缩放到 a=1.70 m，然后检查体积。
- 提交普通 JSON 文件，不使用符号链接或管道，大小不超过 1 MiB；不读取自报热流、几何数组、平衡输出或优化日志。

得到可用候选后即可写入最终文件，再用更好的候选替换。替换时先写临时文件再改名。正式评测在解题结束后读取一个提交快照，并重新生成全部物理输入。

## 5. 从边界到成绩

### 5.1 独立重算的物理链

1. 检查提交格式与几何，统一小半径，独立检查体积。
2. VMEC2000 在固定径向网格上求真空平衡；检查原生收敛状态、残差与 Jacobian。
3. 用该平衡计算旋转变换、磁阱、伸长率、磁场梯度尺度；booz_xform 和 NEO 计算有效波纹度；SIMPLE 追踪 α 粒子。
4. `gx_geometry` 从本次平衡重新生成四根通量管，再由固定版本 GX 运行十二个非线性工况。每点使用两个初始扰动种子和两档垂直分辨率。
5. 检查统计平稳、时间相关、重复计算与网格差异，再用公开公式计算分数。

### 5.2 直接降低最大的热流

每个点的热流都换算到同一个参考长度 a=1.70 m、参考场 B_ref=5.70 T 的 gyro-Bohm 单位。为计入有限计算的不确定性，以细网格的时间平均热流 q_k 为中心，误差余量 h_k 为两档统计半宽之和，再加两档均值差的绝对值。定义：

```text
u_k = q_k + h_k
J = max(u_1, …, u_12)
```

**J 越小越好。** u_k 是按本题数值规则得到的热流上界估计，不是连续物理模型的严格误差界。十二点都必须完成并通过第 7 节的数值检查；任一点未解析，不能只取其余点排名。

例如，两份提交的十二点最大热流上界分别为 10 和 8，后者排名更高，即使某个较低热流点从 1 增加到了 4。这里比较的是最大热流，不要求每点都低于公开起点。所有热流保留原生有符号数值，不把负值裁成零。

### 5.3 七项要求与平台分数

原始指标 J 用于比较物理表现。为沿用平台的 S∈[0,1] 输出，使用固定的单调映射；无需参考成绩或预设最优解：

```text
无效提交或候选未解析： S = 0，保留具体状态

有效但未达标：        S = 0.5 × exp(−Σ v_j²)，严格小于 0.5

有效且全部达标：      S = 0.75 − arctan(J)/(2π)，位于 (0.5, 1)
```

arctan 使用弧度，J 是上述共同单位下的无量纲数值。映射只用于平台展示，不引入新的物理目标。

违反量 v_j 公开定义如下；表中的尺度只用于未达标进展分，不改变达标门槛：

| 要求 | v_j |
|---|---|
| 体积 | max(0, (abs(V/V_ref−1)−0.001)/0.001) |
| α 损失 | max(0, (f_α,upper−0.05)/0.05) |
| 有效波纹度 | max(0, (ε_eff,max−0.01)/0.01) |
| 旋转变换 | max(0, (0.30−ι_min)/0.30) |
| 磁阱 | max(0, −W/0.01) |
| 伸长率 | max(0, (κ_max−8)/8) |
| 磁场梯度尺度 | max(0, (2.4−L_∇B,min)/2.4) |

例如 J=10、8、1 时，S 分别约为 0.5159、0.5198、0.6250。这些只是公式演示，不是公开边界的实测成绩。

有效未达标结果报告七项磁与几何观测量，可以在磁约束检查后结束，不要求为不可行边界继续运行 GX。进展分若因舍入达到 0.5，截到小于 0.5 的最大浮点数。

`reward.json` 包含 reward、valid、feasible、evaluator_error；`details.json` 保存主目标、逐点热流与区间、约束违反量、诊断和耗时。缺失的观测量会标明原因；评估器错误标记为 `evaluator_error`。

通过全部要求的提交按较小 J 排名，J 相同则并列；不以四舍五入后的平台分数判定同分。极端数值下，浮点映射保持在 (0.5,1) 内，原始 J 仍完整保留。

## 7. 精确定义和数值规则

有效小半径 a=√(S̄/π)，有效大半径 R_eff=V/(2πS̄)，S̄ 为环向平均截面积。截面伸长率取面积二阶中心矩阵特征值之比的平方根。W=min_s(−dV′/ds/V′(0))，逐面检查 0.05≤s≤0.95；ε_eff=EPSTOT^(2/3)；L_∇B=√2 abs(B)/‖∇B‖_F，在边界取最小值。

磁评估采用公开评估器所列的固定程序版本；VMEC 末级径向网格固定为 257。几何网格为每场周期 256 个截面、每截面 512 点。VMEC 的 MPOL、NTOR、残差、重试、Boozer 转换、NEO 五面和 SIMPLE 发射、轨道设置见公开评估器；同时登记在 `case.json`。SIMPLE 未解析数 N_U 超过 4096 的 0.1% 时无有效轨道成绩，否则 N_L+N_U 进入损失上界。

湍流规则为：

| 内容 | 固定设置 |
|---|---|
| 几何 | s=0.5，四个规定中心；每根管长度 75a；由维护中的 gx_geometry 生成 |
| 基准与复核网格 | nx=ny=64 与 128；沿场 96 点，Hermite 8、Laguerre 4；都运行两个种子 |
| 垂直盒 | x、y 的盒参数均为 10，对应共同尺度下周期长度20πρ_i；换算到共同参考回旋半径与 x=a√s 坐标 |
| 沿场边界 | forced periodic；case 中的 `periodic` 是固定上游版本的同义设置，均不裁剪或自动匹配几何端点。热流比较对应四个规定中心、75a 长度及这一有限域边界条件 |
| 时间 | τ=t v_ti/a 到 1605，末端 5 用于覆盖诊断输出；舍去 τ<400；只统计 τ∈[400,1600] |
| 初态 | density 扰动，幅度 10⁻³，随机种子 2026100801、2026100802；无外部强迫、无重启输入 |
| 数值 | RK3、CFL=0.9；原生 hypercollisions、hyperdiffusion，D_hyper=0.05；采用有限 Laguerre–Hermite 谱截断，不使用额外的解析矩闭合 |
| 统计 | 每次尾窗分成 12 个长度 100 的块；两个种子的块均值等权合并，使用 Student t 区间 |
| 相关检查 | 块长至少为估计相关时间的 10 倍；两个种子的均值，以及每个种子各自的前后半窗，都检查有限窗一致性，避免相反漂移合并后抵消 |
| 误差 | 本次候选的十二点、两档网格共 24 个均值区间按 Bonferroni 的联合 95% 目标构造，采用块近似独立与平稳的统计假设；离散误差估计取两档均值差的绝对值 |
| 分辨标准 | 两档均值差≤本点细网格均值绝对值的 10%；每档统计半宽≤该档均值绝对值的 5%；不满足记为未解析 |
| 诊断 | 原生热流、自由能诊断开启，完整场快照关闭；原生 NetCDF 无损归档，保留完整热流样本及采样频率 |

有限窗一致性使用 `abs(mean(left)−mean(right)) ≤ t_quantile×sqrt(var(left)/n_left+var(right)/n_right)+0.1×abs(mean_of_this_resolution)`。其中 mean_of_this_resolution 是本点该档网格的双种子合并均值。固定窗口内未通过一致性检查的结果记为未解析。均值恰为零时，相应误差容限也为零：精确零信号可以通过，有噪声的近零信号仍需足够精度，不通过人为添加分母下限放行。

统计区间描述本次候选在规定模型中的热流估计。搜索得到的改进可用新种子进一步确认。

热流定义使用共同参考 x=a√s。GX 原生热流中除以平均径向梯度的因子必须恢复；再转换原生 L_GX、B_GX 到本题的共同尺度。v_ti=√(T_i/m_i)，ρ_i=m_i v_ti/(abs(Z_i)eB_ref)，Q_GB=n_iT_iv_ti(ρ_i/a)²。原生梯度因子、参考尺度和物理场强缩放全部写入诊断，不接受候选提供的值。[GX 输入说明](https://gx.readthedocs.io/en/latest/Inputs.html)；[维护中的几何转换](https://github.com/landreman/gx_geometry)
