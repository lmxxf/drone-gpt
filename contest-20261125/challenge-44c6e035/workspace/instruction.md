# 把理想线圈变成有厚度的绕组，还能守住磁场精度吗？

在计算机里，一条没有厚度的曲线就能代表线圈。但真正的聚变磁体需要把许多匝导体绕成有宽度、有厚度的绕组包，周围还要留出绝缘、支撑和安装空间。当电流从一条中心线分散到整个截面，磁场也会随之改变。

这让仿星器线圈设计多了一层关键取舍：一个中心线拟合得很好的磁场，加入绕组厚度后是否仍然准确？相邻绕组是否还有间隙？截面沿三维曲线转动时，会不会扭得过快？安装时出现毫米级偏移后，这些要求又能否同时保持？

**你的任务是设计一组具有固定矩形截面的线圈绕组包，联合调整中心线、截面朝向和允许改变的电流，使它们在规定装配偏差下尽量准确地实现目标磁面，并满足空间、弯曲、扭转和电流预算。**

## 1. 科学目标（Goal）：让磁场设计面对绕组的实际尺寸

### 1.1 为什么厚度和朝向会改变磁场？

磁面是一层磁场与之相切的封闭曲面。仿星器希望形成嵌套的磁面，为约束等离子体提供磁几何基础。对于给定目标面，穿过表面的法向磁场越小，线圈场与目标面的匹配通常越好。

实际绕组中的电流分布在不同位置，各部分对目标面磁场的贡献并不相同。矩形截面的长边朝哪里，也会改变这些电流路径。因此，设计变量不再只有中心线：绕组包的截面朝向成为可以利用、又受到制造预算约束的自由度。[有限截面线圈研究](https://arxiv.org/abs/2009.00196)

### 1.2 场精度、占用空间与装配容差要一起设计

本题给定四条独立线圈，按对称性形成十六个绕组包。每个包的截面固定为 0.40 m × 0.60 m，不能缩成细丝来取得优势。你可以让截面沿中心线平缓转动，但必须限制单位弧长的材料框架扭转；电流也受到安匝数和绕组包平均安匝密度的约束。

设计完成后，十六个绕组包分别受到平移和转角误差。同一包内的电流路径一起移动，不会各自随机散开。评价因此同时涉及有限截面效应和整包装配误差。几何验收看整个包的保守外包络，不能用中心线之间的距离代替绕组间隙。

### 1.3 怎样的结果有科学和工程意义？

最终提交 `coils.json`，包含四条中心线的形状、截面旋转系数和电流。评估器用 SIMSOPT 的原生多细丝近似计算绕组包磁场；全部要求通过后，128 个规定装配工况中的最大法向场误差越小，成绩越好。

有价值的成果是一个能同时容纳绕组厚度、空间与装配预算的场匹配设计，并能说明厚度和截面朝向如何影响性能。本题是有限截面磁设计模型：均匀分配等效电流，尚未指定导体材料、匝间连接、冷却和支撑结构。它比中心线模型更接近工程设计，但分数不代表超导临界电流、应力、失超保护或整机可建造性认证。

## 2. 固定设备与绕组条件（Input and constraints）

目标是公开 Landreman–Paul QA 构型的外边界，文件为 `/app/reference/target.vmec`。QA 表示磁场强度接近准轴对称；本题保持目标面不变，研究怎样用外部绕组实现它。

| 条件 | 定义 |
|---|---|
| 目标尺度 | 有效小半径 a=1.70 m，使用 `case.json` 中固定长度倍率 |
| 目标场强 | 目标面面积加权 RMS 磁场 5.70 T |
| 场模型 | 真空；SIMSOPT 1.10.6 原生有限截面多细丝及 Biot–Savart |
| 架构 | N_FP=2，四条独立中心线；名义仿星器对称，展开为十六个绕组包 |
| 中心线 | Cartesian Fourier 最高阶 8；长度单位 m |
| 绕组截面 | 固定矩形，宽 w=0.40 m、高 h=0.60 m，面积 0.24 m² |
| 截面朝向 | 原生 centroid 材料框架上叠加最高阶 2 的周期旋转 α(t) |
| 可调整电流 | 第二至第四个基圈；第一圈固定 19,167,004.61524802 A·turn，相对容差 10⁻¹⁰ |
| 电流含义 | 整个绕组包的等效安匝数；按统一求积权重分配到截面节点，不是每根求积细丝都携带全部电流 |

以下是本题共同的设计预算。矩形尺寸、间隙和扭转门槛用于定义一个明确、可复算的工程设计问题，不是所有聚变磁体通用的制造极限。

| 要求 | 达标条件 |
|---|---|
| 中心线用量 | 四条独立中心线总长度保守上界 ≤200 m；全装置是其四倍 |
| 中心线弯曲 | 曲率保守上界 ≤0.55 m⁻¹ |
| 中心线空间 | 圈间距离下界 ≥0.85 m；到目标面 ≥2.40 m；非局部自距 ≥0.50 m |
| 绕组包间隙 | 全允许刚体装配范围下，不同包的距离保守下界 ≥0.10 m |
| 绕组到等离子体 | 整包到固定目标面的距离保守下界 ≥2.40 m |
| 绕组非局部自距 | 中心线弧长分隔不少于 4 m 的包截面之间，距离下界 ≥0.10 m |
| 装置包络 | 中心线及整包均满足 2.50≤R≤22 m、abs(Z)≤10 m，含允许装配误差 |
| 局部弯曲余量 | r_pack × κ_upper ≤0.5；r_pack=√(w²+h²)/2，避免截面局部折叠 |
| 材料框架扭转 | 单位中心线弧长的原生框架扭转绝对值，数值上界 ≤0.25 m⁻¹ |
| 电流预算 | 各基圈为 [1,25] MA·turn，且 I/(w h)≤100 MA·turn/m² |
| 模块架构 | 每圈与指定参考圆的绝对 Gauss 链接数为 1；圈间绝对链接数总和为 0；整数差容差 0.001 |
| 名义磁场 | 未装偏时的有限截面法向误差数值上界 ≤0.001 |
| 场强与方向 | 名义及全部规定工况：RMS 相对 5.70 T 偏差上界 ≤2%；采样面上 3≤abs(B)≤9 T，−B_φ≥3 T |

这里的 I/(w h) 是按整个绕组包面积归一的平均安匝密度，不能代替超导材料的临界电流曲线。扭转指实际材料框架绕切向的转动率，包含中心线框架本身的变化，不能只用 α 的 Fourier 系数大小代替。几何距离使用包的外接圆管，因此是保守验收；外接圆管不合格并不必然意味着矩形实物已经碰撞。

## 3. 从公开线圈走向有限截面设计

`/app/reference/coils_nominal.json` 的中心线来自 SIMSOPT 公开优化线圈 `biot_savart_opt.json`，按目标尺寸和场强缩放，并把第 6–8 阶系数补零；来源、许可和转换倍率见 `reference/source.json`。本版为每条线圈增加五个初始为零的截面旋转系数。

它是一份可运行的研究起点，并不是已满足新版全部约束的工程设计。特别是，加入截面后，参考设计的整包最小 R 保守下界约为 2.338 m，未达到 2.50 m 的要求。改进需要调整形状与朝向，并重新检查场精度和其余空间预算。

有限截面改变了物理模型，旧细丝版的参考误差和 0.75 分不能直接沿用。本版正式组参考值 J_ref≈0.000829361095，公开组 J_ref_search≈0.000878835767，完整精度值分别见 `baseline.json`、`search-baseline.json`。参考设计因整包最小 R 未达标，得分约 0.497893；0.75 只适用于 J=J_ref 且全部约束通过的设计。公开与正式比较各使用对应工况组的参考值。

## 4. 提交中心线、截面朝向和电流（Output）

最终产物为 **`/app/coils.json`**，最大 1 MiB。顶层只有 `nfp`、`order`、`coils`，分别为整数 2、整数 8、四个基圈的列表。每个基圈恰有五个字段：`x`、`y`、`z`、`current`、`rotation`。

以 t∈[0,1) 表示闭合中心线。每个坐标数组有 17 个数，排列为：

```text
[c0, s1, c1, …, s8, c8]
x(t) = c0 + Σ[m=1..8] (s_m sin(2πmt) + c_m cos(2πmt))
```

y、z 相同；系数为米，绝对值≤100。`current` 为有限安匝数，格式上 abs(current)≤10⁹，性能仍受第 2 节约束。电流方向沿中心线参数 t 增加方向；反转参数方向会改变磁场，不能只根据正安匝数判断物理极性。

`rotation` 的五个数为 `[a0, s1, c1, s2, c2]`，单位 rad，每个绝对值≤π：

```text
α(t) = a0 + s1 sin(2πt) + c1 cos(2πt) + s2 sin(4πt) + c2 cos(4πt)
```

它叠加在 SIMSOPT `FramedCurveCentroid` 框架上。框架中的 centroid 是均匀参数采样位置的算术均值；装配旋转支点则是中心线弧长质心，两者定义不同。求积点数足以解析本题 Fourier 系列时，前者等于中心线的常数项。框架退化、零切向速度和无法解析的几何均不接受。

不接受额外字段、重复 JSON 键、NaN、Infinity 或布尔数值。直接复制公开参考文件可得到完整合法格式，之后修改中心线、`rotation` 和允许变化的电流。评估器不会替你重新优化。

先用原生 `coils_via_symmetries` 作名义展开：环向旋转 2πk/N_FP，仿星器对称变换 (x,y,z)→(x,−y,−z)，对称翻转圈的有符号电流取反。截面朝向随对应线圈一起变换。十六个实体按固定 16384 点弧长质心的环向角、xyz、完整空间 Fourier 系数、有符号电流和旋转系数依次排序。误差数组绑定这个顺序；第二至第四基圈换序不改变评分，第一圈仍表示固定电流电源。

## 5. 怎样比较磁场与装配鲁棒性？

### 5.1 每个绕组包作为整体安装

对包 j 的任意材料点 X，装配后位置为：

```text
X′ = c_j + δ_j + Exp([ω_j]×)(X − c_j)
```

c_j 为中心线弧长质心。δ 的三个分量各自均匀分布在 ±0.010 m，旋转向量 ω 的三个分量各自均匀分布在 ±0.001 rad。使用 SciPy Rotation 的旋转向量定义，不是顺次 Euler 转角。电流不变，同一包内全部电流路径承受同一个刚体变换。

公开搜索组、正式保留组各有独立的 128 个规定工况，各分为 2×64；来自相同分布，发布前冻结种子并保存哈希。名义状态另算。这里研究整包装配误差，不包含沿线制造变形、匝间位移或安装后的主动校正。

### 5.2 用整个绕组产生的场评价目标面

所有场积分覆盖完整环，并按目标面的实际面积加权：

```text
e_k = sqrt[∫(B_k·n)² dA / ∫abs(B_k)² dA]
    = sqrt[2 × SIMSOPT SquaredFlux(S,B_k,definition="normalized").J()]
e_k,upper = e_k,final + Δe_k,space + Δe_k,section
J = max(e_k,upper)，取 128 个装配工况
```

名义误差单独作为约束。e 和 J 无量纲；0.001 表示这个平方积分比开方后的 0.1%，不是粒子损失率。B 是所有绕组包电流路径的总场；不能用中心线场或选手自报的场代替。

J 是规定有限工况中的最大值，不是全部真实误差的最坏情况，也不是概率分位数。较低的 J 表示目标面场匹配更稳健；实际磁面、磁岛和粒子轨道需在所产生的线圈场中另行研究。

### 5.3 满足工程预算后，按同一个目标排序

```text
全部约束达标： S = 0.5 + 0.5 × J_ref/(J_ref+J)
有效但未达标： S = 0.5 × exp(−Σv_j²)，严格小于 0.5
```

上限违反量为 max(0,(x−阈值)/尺度)，下限为 max(0,(阈值−x)/尺度)。尺度等于表中正阈值，固定电流相对误差尺度为 10⁻¹⁰，链接误差尺度为 0.001；唯一实现及全表在公开 `eval.py`、`case.json` 中。优秀的磁场误差不能抵消空间等约束失败。

只有全部约束通过且 J=J_ref 时，公式才给出 0.75；参考设计本身若有约束失败，只获得相应进展分。开发比较使用公开组的 J_ref_search，正式评分使用保留组 J_ref，不混用两组参考值。

缺失、格式或几何无效为 `invalid_submission`；数值未解析为 `candidate_unresolved`，两者 reward 为 0。缺依赖、参考校准或可信运行环境为 `evaluator_error=1`，不作为选手的物理失败排榜。数值有效性要求见第 7 节。

## 7. 数值定义与几何验收依据

### 7.1 固定截面，多细丝只是求积方法

每条中心线生成 N×N 条原生 `CurveFilament`。采用 [NumPy 的 Gauss–Legendre 求积](https://numpy.org/doc/stable/reference/generated/numpy.polynomial.legendre.leggauss.html)节点 ξ_i、权重 q_i（定义域 [-1,1]，Σq_i=2），截面位置为 `(w ξ_i/2, h ξ_j/2)`，电流为 `I q_i q_j/4`。权重表示均匀连续电流分布的积分份额；不同节点权重不表示任意调配真实电流密度。N 增加只细化积分，不改变真实截面尺寸和总安匝数。这是矩形截面中均匀分配电流的连续模型近似，不表示实际只有 N² 匝，也不计真实导线端部和连接。

四档计算为 `(全环φ点数, θ点数, 线积分点数, 截面每边点数)`：

```text
(64,32,256,3)
(128,64,512,3)
(256,128,1024,3)
(256,128,1024,5)
```

空间误差 Δe_space 取第三与第二档之差的绝对值；截面误差 Δe_section 取第四与第三档之差的绝对值。二者相加，避免同时改变两类网格时误差偶然抵消。每个工况要求二者之和≤max(10⁻⁸,0.001 e_final)。RMS、场强最值及 −B_φ 最值也分别计算这两项差，总和须≤0.001 T，验收取末档加减该差的更不利值。

此外，名义状态与两组各自最坏工况必须用 `(512,256,2048,7)` 复核，目标面采样在两个角方向均错开半个网格。复核 e 差须满足相同 0.1%/10⁻⁸ 门槛，各场强量差≤0.001 T；差异不能改善分数。被复核工况以两次 e 的较大值，再加原空间/截面差及复核差计算上界，并重新取全部工况最大值。这样可以发现依赖特定网格位置、截面离散或最坏样本低估的结果。

这些是规定的数值比较估计，不是连续场的严格误差界。截面旋转使用原生 `FrameRotation`，缩放固定为 1；单位弧长扭转由原生 `frame_torsion()` 计算，在 4096/8192 个中心线点上复核。各圈最大绝对扭转的两档差须≤0.0001 m⁻¹，验收使用末档最大值加差值。

### 7.2 给整个包留空间

几何中心线取 16384 点，目标面取 1024×256 点。位置由原生曲线和表面生成；Fourier 导数的三角界用于扣除采样覆盖半径，中心线最小速度下界必须严格为正。设归一化参数的一至三阶导数界为 V、A₂、A₃：

```text
覆盖半径 = V/(2N)
长度上界 = 原生长度 + A₂/(4N)
v_min = min(abs(Γ′)) − A₂/(2N)
曲率上界 = max(κ) + [A₃/v_min² + 3A₂²/v_min³]/(2N)
```

中心线 j 的任意允许装配位移上界为 `d_j=√3·0.010+2r_j sin(√3·0.001/2)`，其中 r_j 为中心线相对装配支点的半径上界。中心线距离先扣采样误差与 d_j，再扣截面外接半径 r_pack：包间与非局部自距扣 2r_pack，到目标面扣 r_pack；R/Z 包络同样向外扩 r_pack。这覆盖矩形截面的每个点，不只检查求积细丝之间的空隙。

本题的包间保守距离、目标面间距及外包络可覆盖全部规定幅度的刚体误差；磁场目标仍只覆盖 128 个工况。非局部自距按中心线弧长≥4 m 定义，沿用含弧长与位置覆盖补偿的邻域查询；局部弯曲条件另外限制截面折叠。这些条件不替代安装路径、连接和支撑结构设计。

材料框架还检查投影到中心线法平面的径向向量具有正的连续下界，排除 centroid 框架奇异。链接诊断使用 512 点，参考圆为 `(R_eff cos(2πt),R_eff sin(2πt),0)`。SIMSOPT 的绝对链接数会取整，整数差容差不能冒充未取整 Gauss 积分的误差估计，也不能独立证明任意链环的拓扑。
