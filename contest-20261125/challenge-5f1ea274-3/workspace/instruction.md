# 把仿星器做小，让聚变粒子留下来

仿星器的线圈常常弯得很复杂。那些弯曲承担着一件关键的事：让磁力线绕着等离子体扭转，把粒子留在环里。三维形状设计得足够好，约束所需的扭转就可以由外部线圈提供，不必依靠流过等离子体的大电流。

可到了设计电站的时候，线圈又得退开，给包层和屏蔽留出位置。我们还希望机器更紧凑。空间缩小了，磁场却仍要留住热燃料和聚变产生的高能粒子。这几件事，会一起争夺三维形状的设计余地。

这道题请你从等离子体的形状入手，寻找一个更紧凑的仿星器。**最终提交一份 `boundary.json`：用一组系数描述外边界，在满足全部六项要求的前提下，把纵横比 A 做得尽可能小。** 评估器从这份几何描述重新求解磁场、追踪粒子，再给出成绩。题目提供了公开构型、固定版本的计算环境和复现用评估器，可以直接从这些构型开始，也可以寻找新的形状。

题目提供的五个公开构型里，满足全部六项要求的最小纵横比是 6。如果找到一个同样达标、纵横比为 4 的边界，就把有效大半径从 10.2 米降到了 6.8 米，小半径和磁场强度保持相同。这样得到的边界是一份可复算的证据：这些粒子约束、磁场结构和几何要求，可以在更小的环上同时满足。研究者可以拿着这个具体形状，继续计算有限压强下的性能、设计真实线圈。

## 1. 聚变的两条环形路线

### 1.1 一圈磁场，还差一个扭转

聚变的燃料要热到原子核能够频繁发生反应。此时燃料已经成为等离子体，核心高温区域必须与器壁隔开。磁约束利用带电粒子绕磁力线回旋的性质，尽量把它们的运动限制在磁场里。

先把磁场围成一个环，就避开了直线磁场的两端。可是，环内侧和外侧的磁场并不一样，磁力线本身也在弯曲；粒子转着转着，仍会发生横跨磁力线的漂移。磁力线需要一边绕着大圆走，一边绕截面转。在良好的约束磁场中，它们铺在一层层套在一起的封闭曲面上，这些曲面称为“磁面”；设计的目标是尽量把粒子的运动限制在各自磁面附近。

托卡马克和仿星器都需要这种扭转，但产生它的方式不同。

**托卡马克让等离子体中的电流参与建立约束磁场。** 外部线圈提供环向磁场，大等离子体电流提供主要的极向磁场，两者合成螺旋磁力线。它的轴对称几何有利于粒子约束，也积累了丰富的实验经验。走向电站时，持续维持、精确控制电流，以及处理与电流有关的不稳定性，都是重要课题。

**仿星器把约束所需的扭转交给外部线圈的三维形状。** 它不必依靠大等离子体电流建立约束，具有持续运行的潜力。线圈的形状决定磁场结构，设计工作也就从控制电流更多地转向了优化三维形状。

这对电站很有吸引力：减少持续驱动大等离子体电流的负担，也降低与这类电流相关的破裂风险。仿星器仍需加热、排热和稳定性控制，运行时也可能存在自举电流。托卡马克则在发展非感应电流驱动，探索自己的稳态运行方案。[IPP 的介绍](https://www.ipp.mpg.de/4047930/04_16)说明了两条路线各自的特点。

### 1.2 粒子走的路，比磁力线更复杂

有了扭转，事情还没结束。粒子并不严格沿一根磁力线运动。一部分粒子会被较强磁场反射，在两个反射点之间来回运动，成为“捕获粒子”。磁场的弯曲和强弱变化会让粒子横跨磁力线漂移：在一些路段向外偏，在另一些路段向内偏。如果一次往返总是向外多挪一点，这些偏移就会不断积累，粒子最终离开原来的磁面。

好的三维磁场设计，要让不同路段向内、向外的偏移尽量抵消。**准对称**是一种巧妙的选择：磁面可以没有几何轴对称，但在特定磁坐标中，每个磁面上的磁场强度只依赖一个角度组合。这种隐藏在磁场强度中的对称性，为粒子运动提供了有利于约束的规律。更一般的**全向性**直接要求捕获粒子一次往返的平均径向漂移为零。准轴对称（QA）、准螺旋对称（QH）和准等动力（QI）是沿着这些思路形成的常见设计方向。

改变几组形状系数，就可能减少粒子向外积累的漂移，改善约束。[Landreman–Paul 的准对称研究](https://arxiv.org/abs/2108.03711)展示了这种可能性。在这道题里，QA、QH、QI 可以帮助选择搜索方向，成绩则由实际计算的粒子损失和相关指标决定。

### 1.3 紧凑设计的物理代价

如果把装置的所有尺寸一起缩小，而粒子的能量和磁场不变，粒子轨道相对于装置就会变大，原来的约束性能未必保得住。本题采用另一种比较：固定等离子体的有效小半径 a=1.70 m 和轴上磁场 5.70 T，只改变形状与纵横比。

对圆截面圆环，纵横比 A=R/a：R 是环中心到截面中心的距离，a 是截面半径。较小的 A 表示环更“厚”、中心空隙更小。对三维边界，本题用面积和体积定义相应的有效半径。固定 a 后，A 从 6 降到 4，相当于有效大半径从 10.2 m 降到 6.8 m。

更短的大半径，让线圈、真空室和外围部件有机会围绕一个更小的等离子体环布置。紧凑仿星器研究的重要动机，正是控制装置规模与建造成本；[ARIES-CS 电站研究](https://www-pub.iaea.org/MTCD/Meetings/FEC2006/ft_p5-26.pdf)也强调，线圈与等离子体之间必须容纳包层和屏蔽，磁场设计与工程空间需要一起考虑。尺寸上的机会能否变成成本上的改进，还要由真实线圈、功率需求和工程设计来判断。

小半径相同，环却绕得更紧了。内侧空间变少，环向曲率增强，原本良好的磁场规律可能被破坏。用更强的形变修补约束，又可能把某些截面拉得过长，或者逼着线圈贴近等离子体。

线圈与等离子体之间还要放下电站的其他部件。氘氚聚变产生带电的 α 粒子和不带电的中子：α 粒子留在磁场里，把能量交给燃料，帮助维持高温；中子飞出磁约束区域，能量由外围部件接收。含锂的增殖包层利用中子产生氚，屏蔽保护线圈，这些部件都需要空间。因此，留住粒子的形状还得允许线圈离等离子体足够远。[IPP 的聚变反应介绍](https://www.ipp.mpg.de/15047/kernfusion)说明了两类反应产物和氚的来源。

**本题要寻找的是这些要求能够同时成立的更小纵横比。** 它考察固定小半径下的紧凑程度；纵横比本身不等于电站成本，也不等于同聚变功率下的装置尺寸。

### 1.4 更小的边界带来的改进

沿着一系列相关形状把 A 从 6 降到 5，再降到 4，每一步都要在相同的小半径、场强和粒子能量下检查约束性能，同时保留合适的磁场结构、截面形状和线圈空间。

如果六项要求仍然满足，就把这套条件下已经验证的设计范围推进到了更小的大半径。小半径、磁场和粒子能量都没有变，改进来自三维形状本身。边界文件和评测生成的物理量让其他研究者能够复算、比较，也让后续的有限压强平衡、自举电流和真实线圈研究有一个经过检查的具体起点。

如果缩到某个 A 后，一项要求先不再满足，记录下这个变化也有价值。它能说明这组形状在缩小时，首先遇到的是粒子损失、磁场结构还是线圈空间的限制，为下一轮调整指出方向。这种结论适用于已经搜索和复算的形状范围；判断更一般的尺寸限制，还需要比较其他构型和搜索路径。

从真空边界到能发电的装置，还要经过有限压强、真实线圈、输运和工程设计等检验。这里先检验外部三维成形本身的能力，为后续设计提供更紧凑的候选。不同形状放到同一组条件下计算，得到的改进才能直接比较。

## 2. 粒子约束、磁场结构与线圈空间

设计对象是等离子体最外层磁面的形状，称为“边界”。给出边界后，评估器求解边界内的固定边界真空平衡；你不需要提交线圈文件或自己报告的磁场。

统一条件如下：

| 条件 | 本题的取值与含义 |
|---|---|
| 压强与电流 | p=0，各磁面包围的净环向电流 I_t(s)=0；只考察外部成形提供的真空磁场 |
| 大小与场强 | 有效小半径 a=1.70 m，轴上 Boozer 零模 B₀₀(0)=5.70 T |
| 粒子 | 3.5 MeV α 粒子，无碰撞导心轨道，径向电场 E_r=0，测试粒子近似 |
| 径向位置 | s 是归一化环向磁通，磁轴为 0、边界为 1；ρ=√s，不是直接测量的空间距离 |
| 可改变的量 | 仿星器对称边界的 Fourier 系数，以及 1–6 的场周期数 N_FP |

“真空”是设计中的第一步：先求解没有压强和净环向电流的磁场，单独检查外部成形的效果。实际电站运行时，压强与电流会进一步改变这个磁场，需要在后续计算中加入。

以下六项要求必须同时满足。满足后，A 越小，分数越高；不限制提交边界的 A 上限。

| 要求 | 达标条件 | 物理意义 |
|---|---|---|
| 留住聚变产生的高能粒子 | 核心 α 损失 f_α≤5%：从 s=0.25 发射，追踪 0.2 s | 氘氚聚变产生的 α 粒子应把能量留给等离子体；过早逃逸会减少自加热，并可能集中冲击壁面 |
| 控制热粒子的新经典输运 | 五个指定磁面的最大有效波纹度 ε_eff≤1% | 高能粒子损失低，并不保证热粒子的漂移输运低；ε_eff 衡量低碰撞频率下的一类新经典输运 |
| 保持足够的磁力线扭转 | s∈[0.05,0.95] 上 min(abs(ι))≥0.30 | 旋转变换 ι 表示磁力线每绕大圆一圈，平均绕截面多少圈；零净电流条件下，这种扭转由外部成形提供 |
| 在考察区间保持真空磁阱 | 逐面磁阱指标 W≥0 | 磁阱是有利于交换模稳定性的几何性质，为继续研究有限压强平衡提供基础 |
| 避免截面过度拉长 | 最大伸长率 κ_max≤8 | 防止通过极端细长的截面换取其他指标；这里按截面内部面积的二阶矩计算 |
| 保留线圈远离等离子体的可能性 | 边界上 min(L_∇B)≥2.4 m | 磁场变化越急，通常越难用远处的线圈产生；用磁场梯度尺度检查线圈距离的潜力 |

α 损失和有效波纹度分别考察高能粒子与热粒子。α 粒子留得住，聚变释放的这部分能量才能用于自加热；有效波纹度低，意味着低碰撞频率下的一类热粒子漂移输运受到抑制。两个指标一起检查，避免只改善高能粒子轨道，却让热燃料更容易流失。

旋转变换描述磁力线的扭转程度。这里要求它完全由外部成形提供，并在考察区间内保持一定下限。磁阱则与稳定性有关：等离子体中相邻细磁通管交换位置，可能引起压强驱动的不稳定性；具有磁阱的几何为抵抗这类运动提供有利条件。因此，即使一个边界的粒子损失很低，也仍要检查这些磁场结构。

伸长率约束截面的拉长程度：圆截面的 κ=1，椭圆的 κ 是长短半轴之比，复杂截面按内部面积的二阶矩计算。磁场梯度尺度 L_∇B 则描述边界处磁场的变化尺度。变化很急的磁场，通常需要更近的线圈才能实现；较大的最小 L_∇B 为包层和屏蔽留出空间提供了更有利的设计条件。

这些指标保留了初步设计需要的物理信息，也各有适用范围。α 损失只统计无碰撞粒子数，不包含慢化、散射后的能量损失；ε_eff 没有覆盖湍流输运；真空磁阱也需要与有限压强下的完整稳定性计算结合。

L_∇B 的 2.4 m 门槛来自特定 REGCOIL 设定下与约 1.2 m 线圈距离的经验关系。达到这个门槛，说明线圈距离代理量满足要求，实际线圈仍需另外设计。[Kappel、Landreman、Malhotra 的研究](https://arxiv.org/abs/2309.11342)说明了这种关联。

这些要求之间的牵制，在已有构型上就能看见。

先看两个纵横比同为 6 的 Landreman–Paul QA 边界：它们都很好地约束了 α 粒子，却因磁阱不同得到很不一样的分数。再看 ESTELL：环已经更紧凑了，约四分之一的测试 α 粒子却没能留下来。更小的环和更好的约束，各自做到并不够，难处是把它们放在同一个形状里。

在这五个构型中，Landreman–Paul QA+well 以 A=6 满足了全部要求，是一个明确的改进起点。找到 A<6、仍满足全部要求的边界，就能在这套条件下取得更紧凑的结果。A=6 是这组已测构型的最好结果，整个领域还有其他值得探索的设计。

你可以从这些边界出发，逐步调整形状，也可以生成新的候选。无论采用哪种方法，交给评估器的都是同一种几何描述。

## 4. 用 JSON 描述边界形状

最终产物只有一个文件：工作目录中的 **`boundary.json`（即 `/app/boundary.json`）**。

可以把它理解为一份几何配方：每一行给出一种形状分量，以及加多少。评估器把这些 Fourier 模叠加起来，得到等离子体外边界，再求解边界内的磁场。文件只需要这份几何描述。

下面是最小的格式示例：

```json
{
  "nfp": 2,
  "modes": [
    {"m": 0, "n": 0, "rbc": 1.0, "zbs": 0.0},
    {"m": 1, "n": 0, "rbc": 0.17, "zbs": 0.17}
  ]
}
```

| 字段 | 含义 |
|---|---|
| `nfp` | 绕整台装置一圈，磁场与边界重复的场周期数 N_FP；不是线圈数量 |
| `modes` | 用来叠加出边界的形状分量；未列出的分量为零 |
| `m` | 极向模数，控制绕截面一圈的变化 |
| `n` | 环向模数，控制一个场周期内的变化；实际公式中还有 N_FP 因子 |
| `rbc` | 柱坐标半径 R 的余弦分量系数 |
| `zbs` | 高度 Z 的正弦分量系数；与 `rbc` 使用同一长度单位 |

具体展开为：

```text
R(θ, φ) = Σ rbc(m,n) cos(mθ − n N_FP φ)
Z(θ, φ) = Σ zbs(m,n) sin(mθ − n N_FP φ)
(x, y, z) = (R cos φ, R sin φ, Z)
```

φ 是绕装置大圆方向的柱坐标角，θ 是绕截面的参数角。两者都用弧度；θ 是描述边界用的角，不是评估器后面计算的 Boozer 角。

在这个示例中，第一项给出 R=1 的中心位置，第二项画出半径 0.17 的圆截面。因为所有 n 都为零，截面沿环向不变：它只是一个普通圆环，没有仿星器所需的三维扭转，**只用于理解格式，不是达标构型**。当 rbc(1,0) 与 zbs(1,0) 不同时，截面成为椭圆；加入 n≠0 的模，截面的形状或位置就会沿环向变化。多个模共同决定完整边界。

输入必须满足以下要求：

- 顶层恰有 `nfp`、`modes` 两个键；`nfp` 是 1–6 的整数，`modes` 是非空数组。
- 每个模恰有 `m`、`n`、`rbc`、`zbs` 四个键。m、n 为整数，rbc、zbs 为有限数，不使用 NaN 或 Infinity。
- 0≤m≤12，abs(n)≤12；m=0 时只保留 n≥0。同一 (m,n) 只能出现一次。
- rbc(0,0)>0，zbs(0,0)=0；边界闭合、无自交、处处 R>0。这个余弦/正弦表示规定了仿星器对称性。
- 系数使用任意一致的长度单位；评估器先整体缩放到有效小半径 a=1.70 m。把所有系数乘以同一个数，不会改善纵横比。

对于已有 VMEC 输入，JSON 中的 n 不含 N_FP 因子，与 `RBC(n,m)`、`ZBS(n,m)` 的 n、m 一致；注意 VMEC 下标先 n 后 m，JSON 字段按名字读取。

得到第一个可用边界后就写入 `boundary.json`，之后用更好的边界替换。替换时先写临时文件再改名，避免文件只写了一半。正常结束或 48 小时时限到达后，正式评估只读取当时的这个文件；评估开始前会停止容器里仍在运行的解题进程。

## 5. 评测流程与评分

### 5.1 从几何到粒子轨道

一次完整评测沿着以下流程进行：

1. **读取和检查边界。** 检查 JSON 与几何，统一缩放到 a=1.70 m，计算 A 和截面伸长率。
2. **求解真空平衡。** VMEC2000 根据这个边界求解内部磁场，检查收敛与坐标有效性，读取旋转变换和磁阱；SIMSOPT 计算边界的磁场梯度尺度。
3. **检查热粒子输运指标。** booz_xform 将磁场转换到 Boozer 坐标，NEO 在五个指定磁面计算有效波纹度。坐标变换让程序能够分析同一个磁场的强度规律，没有改变你的边界。
4. **追踪聚变高能粒子。** 磁场归一到轴上 5.70 T 后，SIMPLE 从 s=0.25 按固定抽样程序和种子发射 4096 个 3.5 MeV α 粒子，追踪 0.2 s，统计越过边界的轨道。
5. **应用公开的评分公式。** 用六项指标判断是否达标，再计算分数。

各阶段都由维护中的物理程序计算，提交者无需填写自报指标。某个阶段无法完成时，评测会保留失败原因。只有拿到完整、有效的物理量，才进入六项要求与纵横比的比较。

### 5.2 先满足六项要求，再比较紧凑程度

分数 S∈[0,1]，有三种情况：

| 结果 | 分数 | 含义 |
|---|---|---|
| 无法得到有效评测 | S=0 | 文件错误、平衡或诊断未完成，或数值未解析轨道过多等；查看失败原因 |
| 评测有效，至少一项要求未过 | 0≤S<0.5 | 六项完成度共同决定分数，支持衡量未达标的进展 |
| 满足全部六项要求 | 0.5<S<1 | 分数只随 A 变化，A 越小越好 |

六项完成度 q 都不超过 1；q=1 表示该项达标：

```text
上限指标（f_α、ε_eff、κ_max）：q = min(1, 上限/实际值)
                                      实际值为 0 时 q = 1
下限指标（ι_min、L_∇B）：    q = min(1, 实际值/下限)
磁阱：W ≥ 0 时 q = 1；W < 0 时 q = 1/(1 + (−W)/0.01)

无效：       S = 0
有效未达标： S = 0.5 × q_α × q_ε × q_ι × q_W × q_κ × q_L
全部达标：   S = 0.5 + 0.5/(1 + e^(A−4))
```

例如，其他五项都满足要求、只有 α 损失为 10%，则 q_α=5%/10%=0.5，得分 0.25。即使这个边界的 A 很小，也还处在未达标区间。满足全部要求后，A=6、5、4、3 分别得到约 0.560、0.634、0.750、0.866 分。

满足全部要求后，分数奖励更小的 A。单项指标超过门槛的部分不再额外加分。

### 5.3 分数与诊断结果

评估器生成两个文件：

| 文件 | 内容 |
|---|---|
| `reward.json` | `reward` 是分数；`valid` 表示评测是否有效；`feasible` 表示是否满足全部六项要求；`evaluator_error` 标记评估器本身的错误。三个标记均为 0 或 1 |
| `details.json` | `metrics` 是最终物理量，`completion` 是各项完成度，`stages` 保存各阶段诊断；失败时有 `invalid` 或 `evaluator_error` 原因 |

因此，看到低分时先看 `valid`，再看 `feasible` 与各项完成度。平衡未解出与“平衡解出，但 α 损失过高”是两种不同结果；评估器内部错误也单独记录。

`metrics` 中的字段为 `aspect_ratio`、`f_alpha`、`eps_eff_max`、`iota_min`、`well`、`kappa_max` 和 `lgradb_min`。其中 f_alpha 与 eps_eff_max 用比例表示：0.05 是 5%，0.01 是 1%；lgradb_min 的单位是米。五个磁面的波纹度、α 损失数 N_L、未解析数 N_U 及 95% 置信区间在阶段诊断中报告。同分依次比较较小 A、f_α、ε_eff，仍同则并列。

正式评分输出在 `/logs/verifier/`。手动复现可以通过 `--reward-dir` 指定自己的结果目录。

## 7. 精确定义与数值设置

### 7.1 各项指标的精确定义

有效半径由环向平均截面积 S̄ 和体积 Vol 定义，对圆截面圆环恢复通常的 R 和 a。旋转变换按每个完整环向周回定义，取绝对值，不除以 N_FP；检查区间为 s∈[0.05,0.95]。

有效波纹度在最接近 s=0.2、0.4、0.6、0.8 的半网格面及最外半网格面上计算，取最大值。磁阱按这个区间内每个整网格面上的 V′ 导数判断，边缘的深阱不能补偿芯部的磁山。磁阱与 Mercier 判据的关系见 [Landreman–Jorge](https://arxiv.org/abs/2006.14881)。

定义（[几何](https://simsopt.readthedocs.io/v0.2.0-alpha/simsopt.geo.html#simsopt.geo.surface.Surface.aspect_ratio)、
[NEO](https://princetonuniversity.github.io/STELLOPT/NEO.html)、
[磁阱与 Mercier](https://arxiv.org/abs/2006.14881)、
[L_∇B](https://arxiv.org/abs/2309.11342)）：

- `a=√(S̄/π)`、`R_eff=Vol/(2πS̄)`、`A=R_eff/a`，S̄ 为环向平均截面积，Vol 为体积。
- `κ_max=max_φ √(λ_max(C)/λ_min(C))`，C 为固定 φ 的 R–Z 截面关于面积均匀测度的
  二阶中心矩阵。
- `ε_eff=EPSTOT^(2/3)`，EPSTOT 为 NEO 输出的 ε_eff^(3/2)，参考场取磁面上的最大 B。
- `W=min_s(−(dV′/ds)/V′(0))`，V′=dVol/ds 取自平衡的半网格面；dV′/ds 由相邻两个
  半网格面的差分给出，位于两者之间的整网格面上，取 0.05≤s≤0.95 的整网格面；V′(0)
  由最内两个半网格点线性外推。
- `L_∇B=√2 abs(B)/‖∇B‖_F`，‖·‖_F 为磁场梯度张量的 Frobenius 范数，在边界 s=1 上
  取最小值（SIMSOPT 由半网格数据外推到 s=1，直接在 ρ=1 上计算的程序会略有差别）。


### 7.2 程序设置、有效性与计算成本

| 步骤 | 设置 |
|---|---|
| 几何 | 提交边界先整体缩放到 a=1.70 m；一个场周期内 256 个等距环向截面 × 每截面 512 个极向点做面积、体积、伸长率与自交检查 |
| 真空平衡 | VMEC2000 固定边界，仿星器对称，p=0、I_t=0；MPOL=2m_max+5、NTOR=2n_max+4，且 MPOL≥13、NTOR≥12（m_max、n_max 为提交边界中 rbc 或 zbs 非零的最高模数，数值极小的系数也计入）；角网格 96×96；TCON0=2；磁轴初值由 VMEC 自行估计；三个力残差均 ≤1e−16。末级径向面数先取 257，解不出依次降到 201、101，取能解出的最大面数；每个面数按固定序列重试（降 DELT、加长迭代、加密径向阶梯、末级 GMRES 预条件）；全部尝试共用 4 小时，用尽记为平衡未解出 |
| 场强归一 | 真空解随环向磁通线性缩放，几何、ι、Boozer 角与 ε_eff、W 不变：取 c=5.70 T/B₀₀(0)，B₀₀(0) 由最内两个半网格的 Boozer (0,0) 模线性外推；轨道计算中磁场整体乘 c，不重求平衡 |
| Boozer 变换 | booz_xform；从 mboz=2·MPOL、nboz=2·NTOR 起逐次加倍，直到 φ=0 与 φ=π/N_FP 两个平面上同一物理点处 Boozer 谱与 VMEC 给出的 abs(B) 之差（以 B₀₀(0) 归一）e_B ≤1e−12，上限 mboz=256、nboz=192 |
| 有效波纹度 | NEO（STELLOPT 版，改了一行：近有理面修正按 abs(ι) 计场周期数；未改的源码在 ι<0 时于这类面上返回 NaN，预装的 xneo 已改）；最接近 s=0.2、0.4、0.6、0.8 的半网格面（等距取较小 s）和最外半网格面按 s 升序在一次运行中计算：B_ref 取各面最大 B，R_ref 取首面（s≈0.2）的 Boozer R₀₀，与 STELLOPT 调用 NEO 的方式相同；角网格 300×300，npart=150，acc_req=0.005，全部 Boozer 模 |
| α 轨道 | SIMPLE，4096 条无碰撞导心轨道，α 质量 3.9726 m_p；s=0.25 薄磁通壳内体积均匀（VMEC 角上密度 ∝abs(√g)，等价于 Boozer 角上 ∝1/B²），ξ=v_∥/v 均匀于 [−1,1]；Boozer 正则坐标、辛欧拉积分（integmode=1）、npoiper2=256、relerr=1e−13、multharm=5、ns_s=ns_tp=5；关闭提前分类，不跳过深通行粒子（contr_pp=−1e10）；追踪 0.2 s，首次越过 s=1 计损失；逐粒子读退出码：1、2 为损失，0 为约束，其余（包括 SIMPLE 自己按约束计的数值失败码 4）为数值未解析；抽样程序与种子固定 |
| 线圈空间 | SIMSOPT `vmec_compute_geometry` 由平衡输出计算 s=1 上的 L_∇B，一个场周期内 θ×φ=128×128 取最小值 |
| 时限与内存 | 整次评价限时 12 小时，其中平衡 4 小时、NEO 1 小时，其余留给 α 轨道（a 固定时轨道用时 ∝1/A，成本见下）。SIMPLE 的场样条约占 1.0×10⁻⁵ GiB × ns × (5(MPOL−1)+1) × (5·NTOR·N_FP+1)，超过 110 GiB 的边界无法评价：ns=257、m 与 n 同为最高模数时，N_FP=1、2 不受限，N_FP=3、4、5、6 分别至多 9、8、7、6 |

**有效性。** 平衡输出完整、VMEC 收敛标志正确、三项残差达标、最终网格 Jacobian
符号一致；Boozer 变换到上限仍 e_B>1e−8 时记为数值未解析，无有效 ε_eff。

**α 统计。** SIMPLE 的数值失败轨道计入损失并单独报告：`f_α=(N_L+N_U)/4096`，
N_U/4096>0.001 时无有效轨道成绩。计数步长 0.0244 个百分点，5% 处二项标准误约
0.34 个百分点。

**成本。** 以 Landreman–Paul QA+well（边界最高模数 5）为例，一次评价的墙钟时间：
VMEC 29 分钟（ns=257，8 个 MPI 进程）；Boozer 与 NEO 约 20 s；SIMPLE 2.5 小时
（96 线程，全部轨道约束到 0.2 s，是轨道成本最高的情形）；合计约 3 小时。边界
最高模数更高时，VMEC 的成本明显增加。


L_∇B 的 2.4 m 门槛所采用的经验标定：Kappel 等把 45 个构型缩放到 a=1.704 m，用 REGCOIL 在均匀偏移的绕组面上求线圈距离，场误差 B_RMS=0.01 T、面电流密度上限按 ARIES-CS 的线圈间距取，得到 R²=0.94；该设定下线圈距离约 1.2 m 对应 L_∇B≈2.4 m。它依赖指定的线圈设计设定，不能作为普适的距离换算。
