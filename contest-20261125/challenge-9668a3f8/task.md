# 驾驭燃烧的等离子体，在运行边界内把聚变增益推到最高

聚变电站首先要证明一件事：它产出的聚变功率，远大于为维持燃烧注入的加热功率。两者之比叫聚变增益 Q。ITER 的目标是 Q = 10，用 50 MW 的外部加热换回 500 MW 的聚变功率。到这一步，聚变产生的 α 粒子已经承担了等离子体三分之二的加热，燃烧开始自己养活自己。

可等离子体只能在一条狭窄的走廊里燃烧。电流太集中，中心会周期性地塌陷；压力太高，会长出撕裂的磁岛，甚至破裂；燃料太密，边缘会因辐射而冷塌；流出边界的功率太少，又会从高约束态跌回低约束态。把 Q 推高的每一种办法，都在把等离子体推向其中某一面墙。等离子体内部的电流分布要几分钟甚至更久才能重新排布，一个决定的后果，往往要很久之后才在中心完全显露。

**本题请你设计一个控制器，用六路执行器驾驭一段 120 秒的 ITER 类燃烧放电：在一组隐藏条件各不相同的放电里，让聚变能量与外部加热能量之比 Q 尽量高，同时守住五条运行边界。** 提交一个 ONNX 计算图 `controller.onnx`，它每秒读一次测量，给出六路命令。

## 1. 问题

托卡马克用磁场把上亿度的氘氚等离子体悬在真空室中央。磁场有两部分：外部线圈产生的环向场，和等离子体自身电流产生的极向场。两者合起来，让磁力线沿着环面螺旋前进。螺旋的松紧用安全因子 q 描述：磁力线绕大环 q 圈，才绕小截面一圈。q 一般在中心附近最小，向边缘增大。电流越大、越向中心集中，q 就越低。

等离子体在加热足够强时，边缘会突然长出一层陡峭的温度台阶，叫基座，热量被牢牢锁住，这是高约束态，也叫 H 模。基座越高，核心越热，聚变越旺。氘氚聚变每放出 17.6 MeV，其中 3.5 MeV 由 α 粒子带走并留在等离子体里继续加热燃料，这叫 α 自热。聚变越旺，需要的外部加热越少，Q 就越高。

运行边界就是那几面墙：

- **中心的 q 不能低于 1。** q 低于 1 是中心出现周期性塌陷（锯齿振荡）的前提，是否真的触发还取决于磁剪切、压力和快粒子；锯齿又会为撕裂模播下种子。ITER 的混合运行模式正是把 q 的最小值维持在 1 略上方。
- **压力不能超过磁场的承受力。** 归一化比压 βN 衡量等离子体压力相对磁场有多高。超过理想磁流体的极限，扭曲模会被激发，可能引发破裂；新经典撕裂模甚至在这个极限以下就可能长出来。电流分布越宽，这个极限越低。
- **密度不能逼近 Greenwald 极限。** 这是一个与电流成正比的经验密度标度。越接近它，越容易出现边缘辐射冷却和破裂。
- **边缘的 q 不能太低。** 边缘安全因子 q95 越低，外扭曲模越接近失稳，破裂风险越高。ITER 的常规运行把 q95 留在 3 左右或以上。
- **流出边界的功率要守住 H 模。** 从等离子体流出的功率高于 L–H 转换功率，H 模才稳当。净加热低于转换功率的 80% 时，基座就会塌掉，约束骤降，聚变产出随之崩落。

两件事在放电开始前并不知道。一是这一次的基座能长多高；二是在放电中途某个未知时刻，第一壁的钨会涌入一批，带来额外的辐射损失。控制器看不到这两件事，只能从迟到一秒、带着噪声的测量里推断，并及时调整。

成功意味着：在这个明确的一维输运模型里，在各种隐藏条件下，用更少的外部加热烧出更多的聚变能量，同时不越过任何一面墙。模型不直接模拟锯齿、撕裂模和破裂，而用上面这些公认的运行边界代表它们。

## 2. 等离子体与模型

| 条件 | 本题取值 |
|---|---|
| 装置 | ITER 混合运行平衡：大半径 6.2 m，小半径 2.0 m，环向场 5.3 T，固定的 CHEASE 平衡几何 |
| 燃料与杂质 | 氘、氚各半；氖与电子密度之比 0.005；钨与电子密度之比初始 1 × 10⁻⁵ |
| 演化的量 | 离子温度、电子温度、电子密度、极向磁通（电流分布）四个径向剖面同时演化，电阻率取物理值 |
| 湍流输运 | QLKNN_7_11 神经网络输运模型，作用于 ρ = 0.2–0.9；中心用固定输运系数。ρ > 0.9 在 H 模时是基座，在 L 模时用固定输运系数 |
| 电流 | 欧姆电流、自举电流，以及两路加热驱动的电流 |
| 辐射 | 轫致辐射、电子回旋辐射、杂质线辐射 |
| 基座 | H 模时在 ρ = 0.9 处维持目标温度，离子与电子相同，名义值 4.5 keV；基座密度不固定，由输运和供气决定 |
| L–H 转换 | Martin 标度律给出转换功率。净加热功率高于它时进入 H 模，低于它的 80% 时回到 L 模；基座在 0.5 s 内建立或消失 |
| 起点 | 一段已经稳定下来的 H 模燃烧等离子体：在下面这组执行器设置下预先演化了 1600 s（200 个网格的初态再多演化 900 s）。Ip 10.5 MA，NBI 33 MW（ρ = 0.40），EC 15 MW（ρ = 0.45），供气 0.9 × 10²² 粒子/s |
| 放电 | 120 s |

ρ 是归一化环向磁通半径 √(Φ/Φ_边界)，中心为 0，最外层闭合磁面为 1。它与几何小半径的比例相近，但不相等。模型是 TORAX 1.4.3 与 Gym-TORAX 1.1.1，完整配置见 `/app/case.json`。

## 3. 你可以改变的量

| 执行器 | 范围 | 每秒最大变化 |
|---|---|---|
| 等离子体电流 Ip | 9–13 MA | 0.1 MA |
| 中性束功率 | 0–33 MW | 10 MW |
| 中性束沉积位置 | ρ = 0.20–0.45 | 0.05 |
| 电子回旋功率 | 0–20 MW | 20 MW |
| 电子回旋沉积位置 | ρ = 0.05–0.60 | 0.1 |
| 供气 | 0–3 × 10²² 粒子/s | 1 × 10²² 粒子/s |

**等离子体电流。** 它是托卡马克的脊梁。电流越大，约束越好，Greenwald 密度上限也越高，可以装进更多燃料；但 q 整体下降，中心的 q 更快地逼近 1，边缘的 q95 也在逼近 3。电流只能慢慢改，而且新加的电流先出现在边缘，要经过几百秒才扩散到中心。你现在定下的电流，在整段放电里都会慢慢改写中心的 q。

**中性束。** 把高能中性粒子射进等离子体，同时加热离子和电子（三分之二给电子），并推动一股电流，每 MW 约 0.0625 MA。沉积位置可以在 ρ = 0.2–0.45 之间移动：靠近中心，加热最集中；偏离中心，推动的电流把电流分布往外拉，抬高中心的 q。中性束的功率要经过约 1 s 的一阶滞后才到达等离子体。本模型不计中性束带进来的燃料。

**电子回旋波。** 用毫米波加热窄窄一条带上的电子，并在那里驱动电流。发射镜可以快速转动，沉积位置在 ρ = 0.05–0.6 之间移动。它是塑造 q 剖面的手术刀：放在哪里，那里就多一股驱动电流，再经过电流的扩散，慢慢改写整个 q 剖面。

**供气。** 从边缘补充燃料。聚变功率大致随密度的平方增长，所以密度是最直接的油门；但密度越高，越接近 Greenwald 上限，L–H 转换功率也随之上升，守住 H 模需要更多的功率流出边界。供进去的气要经过边缘的输运，才变成芯部的燃料。它是燃料的唯一来源。

这六路执行器互相牵制。外部加热每少 1 MW，Q 的分母就小一点，但流出边界的功率也少一点。提高密度和电流能让聚变功率上去，同时把等离子体推向 Greenwald 和 q 的墙。用电流驱动把中心的 q 抬起来，要花加热功率。钨涌入时辐射骤增，就得在 H 模塌掉之前补上功率。控制器的价值，在于看清这一次放电是哪一种，然后贴着边界运行。

**命令如何生效。** 控制器在每个整秒给出一组命令。命令先排队 1 s，再在接下来的 1 s 内从上一组命令的值线性过渡到新值。超出范围的部分截到边界，变化超出每秒最大变化的部分截到最大变化。所以在 t 秒发出的命令，在 t+1 到 t+2 秒之间生效；中性束功率再叠加 1 s 的滞后。控制器能从测量里看到每路执行器实际施加的值。

## 4. 控制器能看到什么

每次调用的输入是 25 个测量和 64 个记忆值。测量全部迟到 1 s：t 秒时读到的是 t−1 秒的状态。

| 下标 | 内容 | 单位 | 噪声标准差 |
|---|---|---|---|
| 0 | 时刻 | s | 无 |
| 1 | 聚变功率 | W | 2% |
| 2 | 等离子体热能 | J | 2% |
| 3–4 | 最内一个网格的电子温度、离子温度 | keV | 5%、7% |
| 5 | 线平均电子密度 | m⁻³ | 1% |
| 6 | Greenwald 分数 | — | 1% |
| 7–12 | ρ = 0、0.2、0.4、0.6、0.8、0.95 处的 q | — | 0.1 |
| 13 | q 剖面的最小值 | — | 0.1 |
| 14 | q95 | — | 0.1 |
| 15 | βN | — | 3% |
| 16 | 内感 li3 | — | 0.05 |
| 17 | 边界环电压 | V | 0.02 V |
| 18 | 总辐射功率 | W | 10% |
| 19–24 | 六路执行器实际施加的值，顺序同上表 | MA、MW、—、MW、—、粒子/s | 无 |

百分数是相对噪声，其余是绝对噪声，都是独立的正态噪声。控制器看不到基座温度、钨事件、未来的扰动或未经延迟的状态。记忆在每个场景开始时为 0。

## 6. 运行边界与成绩

每条运行边界带一个违反量尺度。违反量 v 是 120 s 内越界程度的时间平均，再除以尺度，取所有场景中最大的一个：

| 运行边界 | 越界程度 | 尺度 |
|---|---|---|
| q 最小值 ≥ 1 | 1 − q 最小值 | 0.05 |
| βN ≤ min(2.8, 4 li3) | βN − min(2.8, 4 li3) | 0.1 |
| Greenwald 分数 ≤ 0.85 | Greenwald 分数 − 0.85 | 0.02 |
| q95 ≥ 3 | 3 − q95 | 0.1 |
| 流出功率 ≥ L–H 转换功率 | 1 − 流出功率 / 转换功率 | 0.1 |

未越界的时刻记 0。例如某个场景里 q 最小值整段停在 0.95，v = 1，分数乘以 e⁻¹ ≈ 0.37；短暂越界只按它占的时间计。

另有两项保证结果可信：

- **模型适用范围。** QLKNN 是用大量回旋动理学计算训练出来的神经网络，只在训练数据覆盖的参数范围内可信。它的输入是温度梯度、密度梯度、q、磁剪切、温度比、碰撞率等，训练范围列在 `/app/case.json` 的 `qlknn_domain`。在 QLKNN 起作用的每个位置，输入越出训练范围的距离以该输入范围的宽度为单位；每一刻取所有位置、所有输入里最大的越界距离，作为这一刻的越界程度，最多计 1 个范围宽度，尺度 0.05。整段放电都越出范围宽度的 5%，v = 1。
- **求解失败。** 如果模型在某一刻无法继续求解，这个场景停在那里：之后没有聚变能量，外部加热和各项越界程度都按最后的值计到 120 s，另加 v = 未算完的时间占比 / 0.05。

聚变增益与成绩：

```text
Q = 全部场景 120 s 内聚变能量之和 / 全部场景 120 s 内外部加热能量之和
S = Q / (Q + 5) × exp(−Σ v)
```

外部加热是被等离子体吸收的中性束功率和电子回旋功率。

| 全部守住时的 Q | 1 | 2 | 5 | 10 | 11.7 | 20 |
|---|---|---|---|---|---|---|
| S | 0.17 | 0.29 | 0.50 | 0.67 | 0.70 | 0.80 |

Q = 1 是科学上的得失相当。Q = 5 时，α 自热与外部加热一样多，这是 ITER 长脉冲混合运行的目标。Q = 10 是 ITER 的主目标，α 自热已占总加热的三分之二。再往上，等离子体越来越靠自己维持燃烧。

每个场景在两种径向网格（100 和 200 个网格）上各算一次，成绩取两者中较低的那个 S。好的控制策略不应依赖网格的细节。

排名按 S，是否全部守住另行报告。格式无效的提交得 0 分，结果文件会写明原因。

## 7. 提交格式

提交 `/app/controller.onnx`：两个输入 `observation` float32[1, 25] 和 `state` float32[1, 64]，两个输出 `command` float32[1, 6] 和 `next_state` float32[1, 64]。`command` 按第 3 节表格的顺序给出六路命令，单位为 MA、MW、—、MW、—、粒子/s。`next_state` 是下一次调用时的记忆，每个分量须在 [−100, 100] 内。

| 规则 | 限制 |
|---|---|
| 版本 | 一个标准域 opset 导入，版本 18；IR 版本 ≤ 10 |
| 大小 | 文件 ≤ 4 MiB，节点 ≤ 512 |
| 张量 | 所有中间量有静态正维度，每轴 ≤ 4096，每张量 ≤ 65536 个元素 |
| 算子 | Add, Sub, Mul, Div, Neg, Abs, Exp, Log, Sqrt, Pow, Max, Min, Clip, Relu, Sigmoid, Tanh, Softplus, Softmax, MatMul, Gemm, Identity, Concat, Split, Slice, Gather, Reshape, Transpose, Unsqueeze, Squeeze, Cast, Constant, ReduceSum, ReduceMean, ReduceMax, ReduceMin, Equal, Less, Greater, LessOrEqual, GreaterOrEqual, Where, And, Or, Not |
| 禁止 | 循环和条件子图、函数、自定义域、外部权重文件 |
| 时间 | 加载与检查 ≤ 20 s，每次调用 ≤ 1 s |

完整的检查规则以 `/app/interface.py` 为准。违反这些规则或输出非有限值的提交得 0 分。命令超出范围不算无效，会被截到边界。你可以用反馈控制、模型预测控制、离线优化或强化学习得到控制策略，最后把它表达成这样一个计算图；`/app/examples/export_controller.py` 演示如何把一个带记忆的 GRU 策略导出成合法的计算图。

```bash
cp /app/starting-points/nominal.onnx /app/controller.onnx
python -B /app/eval.py /app/controller.onnx --resources /app --output /app/check-001 --coarse-only --trajectories
```

## 10. 精确定义

- **q 最小值**：TORAX 网格面上 q 剖面的最小值。
- **βN**、**li3**、**q95**：TORAX 的原生输出；q95 取 95% 极向磁通处的 q。βN 由热压力计算，不含快离子压力。
- **聚变功率**：TORAX 的原生输出。
- **Greenwald 分数**：线平均电子密度除以 Greenwald 密度 Ip / (π a²)，单位 10²⁰ m⁻³、MA、m。
- **净加热功率**：外部加热、α 自热和欧姆加热之和，减去辐射。
- **流出功率**：净加热功率减去热能的增长率（TORAX 平滑后的 dW/dt）。运行边界用流出功率；H 模与 L 模的切换用净加热功率。
- **L–H 转换功率**：Martin 2008 标度律，按 5.3 T、线平均密度、最外层磁面面积计算，并按燃料平均质量做同位素修正；密度低于 Ryter 最小值时转为低密度分支。
- **积分**：聚变功率、外部加热和各项越界程度都对 120 s 时间积分。

完整的数值设置以 `/app/eval.py`、`/app/plant.py` 和 `/app/case.json` 为准。
