# 给同一批包层材料换个位置，能多产生多少氚？

氘氚聚变每发生一次，就消耗一个氚核，也释放一个高能中子。这个中子进入等离子体外围含锂的包层后，有机会参与反应、产生新的氚。于是，聚变放出的中子又成为补充燃料的重要资源。

但它不会只沿着设计者希望的路线前进：中子可能被其他材料吸收，可能从侧面逃走，也可能穿过屏蔽照射外部部件。真实组件还要容纳结构、冷却和诊断通道。增殖、屏蔽与空间需求必须同时考虑。

**你的任务是在不增加材料库存、不扩大组件、不堵住诊断通道的条件下，重新安排包层材料，让同样的入射中子产生更多氚，同时限制背面的局部快中子通量。**

## 1. 科学目标（Goal）：找到材料摆放位置的价值

### 1.1 材料不仅接收中子，也会改变后方的中子

中子在传播中会散射、减速或被吸收；在铍中，一些反应还能产生额外中子。随着深度增加，中子的数量、方向和能量分布都会改变。锂的两种同位素 Li-6 与 Li-7 对不同能量中子的响应也不同，因此同一份材料放在不同位置，产氚效果可能不同。

这不是给 96 个区域各自寻找一个最佳配方就能解决的问题。前面的区域会改变后方收到的中子；某处增加陶瓷，就必须在其他地方让出库存。你需要把整个组件当作相互关联的输运系统来设计。

### 1.2 孔洞附近，平均值为什么不够？

贯穿组件的诊断孔必须保留。一部分中子沿孔直接穿过，另一部分会在周围散射。即使全背面的平均通量不高，少数位置也可能出现热点。评估因此分别检查 16 块背面区域，并比较法向入射和余弦角分布两种源条件。

你可以调整每个区域的陶瓷体积分数和 Li-6 富集度。陶瓷、铍总量固定，Li-6 总库存有上限，固定冷却与结构空间不能移动。真正需要回答的是：怎样分配有限的中子利用能力，才能兼顾产氚和局部屏蔽？

### 1.3 你将交付怎样的设计？

最终提交 `blanket.json`，记录 96 个区域的配方。OpenMC 会重新构建材料和几何、进行连续能量中子输运，并报告统计不确定性。全部要求通过后，两种入射条件中较低的保守产氚量越高，成绩越好。均匀配方提供一个可复算的起点，分层搜索、灵敏度分析与代理模型等方法都可以使用。[包层参数优化研究](https://www.frontiersin.org/journals/nuclear-engineering/articles/10.3389/fnuen.2025.1694684/full)

有价值的结果是一种在共同库存下更有效的组件布局，以及它如何改变中子路径的可检验证据。本题的产额以每个进入组件的源中子归一；整机燃料自持还涉及包层覆盖率、相邻模块和燃料循环，不能由单个组件的产额独立判定。

## 2. 固定输入与材料约束（Input and constraints）

长度均为厘米。x 指向模块内部；入口是 x=0，y、z 为入口面上的两个方向。

| 固定部分 | 定义 |
|---|---|
| 有限外边界 | x∈[0,96]，y,z∈[−40,40]；六个外表面为真空边界，中子离开后终止，侧向不采用反射或周期边界 |
| 第一壁 | x∈[0,0.2]，天然钨，19.3 g/cm³；前部结构 x∈[0.2,1]，天然铁，7.87 g/cm³ |
| 增殖空间 | x∈[1,61]，六层、每层 10 cm；每层在 y、z 上分为 4×4 块，共 96 个可变区域 |
| 贯穿通道 | x∈[0,91]，y∈[8,18]、z∈[−5,5]，内部为真空；外包 0.5 cm 铁衬层，不能填堵或改动 |
| 冷却空间 | x∈[1,61]，两个氦通道 y∈[−20.5,−19.5]、[19.5,20.5]，覆盖全部 z；各有 0.5 cm 铁侧壁 |
| 固定后屏蔽 | x∈[61,91]，铁/氦体积分数 0.80/0.20，天然铁密度 7.87、氦密度 0.006 g/cm³ |
| 背面观测层 | x∈[91,96] 的真空；4×4 个 20×20×5 cm³ 观测块分别测快中子标量通量，不用全背面平均掩盖通道热点 |
| 核模型 | 连续能量中子输运，指定 294 K，使用与它相差不超过 0.5 K 的冻结库温度点（通常为 293.6 K），自由气体处理；无耗损、无次级光子输运 |

铁是本算例规定的结构材料，不表示已经建模 EUROFER 的全部成分；陶瓷颗粒按均匀介质处理，未解析微观颗粒和晶体热散射。这个范围适合比较本题布局，不构成真实工作温度、材料寿命或屏蔽认证。

每个可变区域的实际体积先扣去通道、衬层和冷却空间。允许改变两个数：

| 变量 | 含义与范围 |
|---|---|
| `breeder_fraction`，bᵢ | 区域中陶瓷颗粒床的体积分数，0.20≤bᵢ≤0.60 |
| `li6_atom_fraction`，eᵢ | 锂元素中 Li-6 的原子份额，0.05≤eᵢ≤0.90 |

余下配方固定为：铍颗粒床体积分数 0.75−bᵢ，铁 0.15，氦 0.10。陶瓷为 Li₄SiO₄，e=0.30 时固体密度 2.30 g/cm³、颗粒填充率 0.64，颗粒床参考有效密度 1.472 g/cm³。改变富集度时保持化学式单元数密度及填充率，密度按 OpenMC 原生平均摩尔质量比例调整，避免同位素质量变化带来虚假的锂总量变化；铍固体密度 1.85、填充率 0.64，有效密度 1.184 g/cm³。混合物用 OpenMC 原生按体积分数混合。颗粒床剩余孔隙按真空均匀化，氦份额另按上述 0.10 及固定通道定义；未模拟颗粒间流动。所有密度、化学计量、天然同位素丰度和核截面由可信评估器设置。

材料库存要求如下，Vᵢ 为扣除固定设施后的区域体积：

```text
Σ Vᵢ bᵢ ≤ 0.40 Σ Vᵢ
Σ Vᵢ (0.75−bᵢ) ≤ 0.35 Σ Vᵢ
Σ Nᵢ(Li-6) ≤ N_ref(Li-6)
```

前两项同时成立时，陶瓷与铍的总量等于均匀参考，只能重新分配。Li-6 库存上限是同一几何中 bᵢ=0.40、eᵢ=0.30 的原生材料计算结果；`Nᵢ` 是 OpenMC 材料原子密度乘区域体积，不用简单平均富集度替代。库存比较容差为参考总量的 10⁻¹⁰。

## 3. 两种入射条件与屏蔽要求

每种工况独立发射等权 14.1 MeV 中子，位置在 x=10⁻⁶、入口 y,z 面上均匀分布，源强固定为 1。通道面积也包含在入口面内，没有只对增殖区发射再重归一。

| 工况 | 方向分布 |
|---|---|
| `normal` | 所有中子沿 +x 入射 |
| `cosine` | µ=cos(angle with +x)∈[0,1]，密度 p(µ)=2µ；绕 +x 的方位角均匀。这是规定的入射电流分布，不是整机等离子体源 |

背面第 j 块的快中子量为 E≥0.1 MeV 的原生 track-length flux，除以该块体积 2000 cm³，单位为 cm⁻²/入射中子。它属于模块后方观测量，没有乘入装置功率或假定磁体距离。

每个工况、每个观测块都必须满足：

```text
fast_flux_upper(k,j) ≤ 1.20 × reference_fast_flux_upper(k,j)
```

参考上界由冻结的均匀布局同条件计算得到。20% 是本题选择的相对屏蔽预算，允许研究产氚与屏蔽的权衡；它不是聚变磁体通用的辐照上限。真正的磁体寿命需要全装置源率、几何和材料损伤模型。这里比较的是候选上界与冻结的数值预算，不据此声称真实通量比值具有同一置信保证。

法向中子中有 1/64 从真空诊断孔直接穿出，材料重分配不能消除这部分。孔覆盖的两个背面块各有 1.953125×10⁻⁵ cm⁻²/入射中子的解析直穿贡献；允许的布局只能改变其余散射贡献及其他区域的穿透。因此通道热点并非都可控制，分数也不奖励封堵通道。结果同时给出各块上界与预算余量，便于区分直穿背景和可改变的屏蔽效果。

## 4. 从一个公开布局开始

`/app/reference_configurations/uniform.json` 给出全部 96 区域的均匀布局 bᵢ=0.40、eᵢ=0.30。它是格式和材料库存都有效的真实输入。

从这份布局出发，可以研究径向分层、通道附近配方和Li-6分配怎样共同改变中子输运。均匀布局同时定义三类比较基准：材料库存、各背面观测块的屏蔽预算，以及评分中的产氚参考值。

参考与候选采用第6节相同的双源、双种子和统计规则。固定参考的最差工况产额下界为 `X_ref=0.2493819552` 氚核/入射中子；各块的固定通量上界按第3节乘1.20后形成候选必须满足的屏蔽上限。

## 5. 输出区域配方（Output）

最终只读取 **`/app/blanket.json`**，最大 1 MiB。顶层恰有 `schema_version`、`case_id`、`regions`；每个区域恰有 `id`、`breeder_fraction`、`li6_atom_fraction`。不接受额外键、重复 JSON 键、重复区域、缺项、NaN、Infinity、布尔数值或超范围数值。

区域名 `Lℓ_Yj_Zq` 中 ℓ=0…5、j,q=0…3；x∈[1+10ℓ,11+10ℓ]，y∈[−40+20j,−20+20j]，z 类似。JSON 中的区域顺序任意，身份按 `id` 读取。

```json
{
  "schema_version": "fusionx-n0-design/v1",
  "case_id": "ported-module-294K-v1",
  "regions": [
    {"id": "L0_Y0_Z0", "breeder_fraction": 0.40, "li6_atom_fraction": 0.30}
  ]
}
```

上面只展示一项字段，完整文件必须包含全部 96 项。可直接复制 `uniform.json` 修改。提交无需包含核数据、几何文件、源文件、tally 或自报成绩；评估器重新生成这些内容。解题结束或 24 小时时限到达后读取当前文件，建议写临时文件再原子改名。

## 6. 完成标准与评分（Completion criteria）

评估从新的、空的工作目录开始，重新加载提交和可信配置，用固定核数据运行 OpenMC，并保存输入 XML、日志、各批 statepoint 和文件哈希。正式计算在干净的可信环境进行，不执行选手提交的代码，不读取选手产生的 statepoint，不继承可改写的依赖与核数据。

每个工况有两个独立种子；每个种子 64 批，每批 300,000 个源中子，无 inactive 批，总计 76,800,000 个源中子。所有批都运行，候选不能选择提前停止。公开复算种子见 `case.json`；正式重算使用另一对独立种子，具体值保留在可信评分包，评测完成后与结果一起报告，便于重放。这样搜索不能直接针对公开随机样本优化。两个种子的算法、批数、粒子数和统计规则相同。候选须满足下述精度要求与4小时输运预算。

原生 `H3-production` 只取增殖空间内 Li-6、Li-7 的贡献，按每个批次先求和，保留二者及各区域间的协方差。每个量合并两个种子的 128 个等粒子数批值，计算均值 µ 和标准误 SE=sample_std/√128。

同时判断两个产氚量及 32 个背面通量，以及冻结参考的同类量，Bonferroni 家族 K=68；q 为 Student t 分布 t₁₂₇(1−0.05/68) 的分位数：

```text
lower = µ − q SE
upper = µ + q SE
X = min(lower_yield(normal), lower_yield(cosine))
X_ref = 同规则冻结的参考 X
```

不裁剪原始值、不用零点估计伪造置信区间。产氚区间半宽必须≤参考对应均值的 0.5%；背面各块半宽必须≤该块冻结屏蔽上限的 5%。每个量至少 90% 的批次有正贡献；两个种子的均值差必须≤q√(SE₁²+SE₂²)。不满足时为 `candidate_unresolved`，不能拿噪声优势计分。这些条件用于检验固定源Monte Carlo批统计的数值精度。

| 结果 | 处理 |
|---|---|
| 格式或允许范围错误 | `invalid_submission`，reward=0，valid=0 |
| 规定时间内未完成输运、统计精度不足 | `candidate_unresolved`，reward=0，valid=0；保留原因，不能当作有效的零产氚 |
| 可信程序、核数据或冻结基线缺失/改变，固定几何中的 lost particle | `evaluator_error`，valid=0；不参与物理排名 |
| 计算有效，材料或屏蔽要求未过 | 0≤reward<0.5，按全部违规计算进展分 |
| 计算有效，全部要求通过 | reward=0.5+0.5 X/(X+X_ref)；X≥0，X_ref>0 |

进展分为 `0.5 exp(−Σ v²)`；每个库存违规 v=max(0,库存/上限−1−10⁻¹⁰)，每个屏蔽违规 v=max(0,通量上界/上限−1)，包含全部三项库存和全部 32 个通量。严格违规而浮点舍入等于 0.5 时取最接近且小于 0.5 的浮点数。有效但统计支持的 X<0 也归未达标，增加 v=max(0,−X/X_ref)。

按评分公式，X/X_ref 为 1.0、1.1、1.2 时分别得到 0.750、0.762、0.773。符合要求后排序只随 X 变化；屏蔽额外余量不成为隐含第二目标。解释布局差异时，应同时查看产氚量的统计区间。

`reward.json` 含 `reward`、`valid`、`feasible`、`evaluator_error`；`details.json` 保留状态、库存、工况与分块的原始均值、标准误、区间、种子差异及输入/输出哈希。正式输出在 `/logs/verifier/`。

## 7. 复算与第一次运行

任务资源及其位置见 `/app/resources.yaml`。`background.zip` 含同源码生成的公开评估器、案例定义、参考输入和指南；核数据库与原生程序由固定镜像单独提供。

在冻结的任务环境中，从 `/app` 执行：

```bash
python -m zipfile -e background.zip background
/opt/neutronics/env/bin/python -I background/eval.py \
  reference_configurations/uniform.json \
  --workdir runs/uniform-001 --reward-dir results/uniform-001 --threads 8
```

工作目录必须为空。正式入口使用冻结基线计算成绩。探索时也可使用以下非排名入口保存原生输运结果：

```bash
/opt/neutronics/env/bin/python -I background/eval.py \
  reference_configurations/uniform.json --physics-only \
  --cross-sections /opt/neutronics/data/cross_sections.xml \
  --openmc-executable /opt/neutronics/env/bin/openmc \
  --workdir runs/discussion-001 --reward-dir results/discussion-001 --threads 8
```

结果标记 `not_ranked`，包含两工况原始量与置信区间；它不是可提交的自报成绩。搜索可以采用低统计量或代理模型，正式评分始终执行本节以上的固定高统计量计算。

解题预算为8 CPU、32 GiB内存、40 GiB存储、无GPU、24小时；原生输运评估预算4小时，外层评分入口另留5分钟收尾。已有8 CPU实测中，均匀布局的完整双工况计算约需16–28分钟，候选布局的耗时可能不同。
